# Gradient-methods

# Gradient Methods for Linear Models

Реализация градиентных методов обучения линейных моделей (логистическая регрессия) с нуля и применение к задаче классификации токсичности комментариев.

---

## Описание проекта

В проекте реализованы:

- бинарная и многоклассовая логистическая регрессия
- аналитические градиенты функций потерь
- градиентный спуск (GD)
- стохастический градиентный спуск (SGD)
- обработка текстовых данных
- эксперименты с параметрами обучения

---

## Реализовано

### 1. Логистическая регрессия
- бинарная
- многоклассовая (softmax)

### 2. Функции потерь и градиенты
- полностью векторизованные реализации
- проверка через численный градиент

### 3. Методы оптимизации
- Gradient Descent (GD)
- Stochastic Gradient Descent (SGD)

### 4. Обработка текста
- очистка текста
- Bag-of-Words
- TF-IDF
- лемматизация (nltk)
- удаление стоп-слов
